🌐 Stateless Request/Response Cloud Apps Tolerates 2–3 s Jitter
  • •Visual UI Masking: REST APIs, microservices, and web chat hide 2,000–3,000 ms p99 tail latency behind loading spinners, skeletons, and async streaming text.
  • •Forgiving Retry Loops: Transparent HTTP backoff retries, cold starts, and chained inline LLM guardrails slow rendering without severing user state.
  • •Half-Duplex Turn Model: Users wait for a visual response before clicking or typing; overlapping input never collides with an active acoustic playback buffer.
📞 Live Full-Duplex Telephony Wire ~200 ms Gap • <1,200 ms Ceiling
  • •Stateful Real-Time Stream: Continuous bidirectional audio across PSTN / SIP / SBC / RTP / BidiRunSession with live Voice Activity Detection (VAD) and barge-in.
  • •Strict Conversational Physics: Human turn-taking expects a ~200 ms natural turn gap and breaks past the <1,200 ms wire ceiling — where silence triggers "Hello?!" collisions or hang-ups.

⚡ Performance: "Count Passes, Not Tokens" ~465 ms / Pass
  • •Single-Pass Budget: ~465 ms median single Gemini pass; 116–236 ms 0-pass Python callback turns.
  • •5 Levers of Speed: Mask (spoken fillers), Cut (eliminate extra LLM hops), Overlap (parallel async_tools), Start Early (ANI prefetch), Shrink (DTO trim).
🛡️ Security: Two-Plane Guardrails 0–5 ms vs ~300 ms
  • •Deterministic Planes: 0–1 ms contentFilter + <5 ms Python Auth Gate & 0-token Guardrail Handoff Intercept vs. ~300 ms/rule inline llmPolicy.
  • •IDOR Defense: Bind account lookup IDs strictly from verified session.state, never raw caller utterances.
⚙️ Reliability: Bounded SLAs & State ≤5 s vs 30 s Harpoon
  • •Transport Safety: Bounded ≤5 s tool SLAs inside the 30 s platform harpoon + stateful circuit breakers.
  • •Harness Invariants: [Part.from_text(text="")] silent close (never parts=[] deaf sessions), _initialized turn guard, and C005 (never regex raw speech — 11% accuracy).
💰 Cost: DTO Compression & Topology 2,400 → 32 Tokens
  • •Clean DTO Projection: 2,400 → 32 token tool responses save -2.4 s cumulative latency and eliminate -5 redundant passes.
  • •Zero-Waste Defaults: 0-token Turn 1 callback greeting (~150 ms) + Single-Agent default (≤15 tools).
