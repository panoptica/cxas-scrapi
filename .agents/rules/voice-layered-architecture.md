# GECX "TCP/IP over OSI" Hybrid Voice Architecture & Diagramming Standard

- **Start at the Physical Wire ("Count Passes, Not Tokens")**:
  - Human phone turn-taking averages a **`~200 ms` conversational gap** (Stivers et al., PNAS 2009), and unpaced silence past **`<1,200 ms`** on the physical telephony wire (`PSTN/SIP/SBC/RTP`, `<800 ms` TTFA target) registers as dead air.
  - **Count Passes, Not Tokens**: A single Gemini pass takes **`~465 ms` median**, 0-pass Python callback turns take **`116–236 ms`**, and inline `tools.x()` calls inside callbacks take **`10–19 ms`**.
  - **`BidiRunSession` First-Message Law**: On live bidirectional streams, `SessionConfig` MUST precede any raw audio frames.
- **Use the 4 Macro-Bands (TCP/IP Builder's Stack) × 7 Agentic OSI Diagnostic Layers** aligned to the **`5+1` CXAS Evaluation Pyramid (`L0`–`L5`, F1 metaphor)**:
  1. **Macro-Band 1 — Acoustic Wire & Turn Pacing (`app.json` + Tool Pacing | Tested by `Eval L5: Audio Sims & Guardrails (F1 Grand Prix)`)**:
     - **OSI L1 (Physical / Acoustic Wire, `<800 ms` TTFA)**: **`gemini-composite-v2` + `sonic-bolt` (`gemini-3.8-flash-lite-tts`)** is canonical with `temperature: 1.0` (`A010`) and SBC barge-in buffer flush (`bargeInAwareness: true`). **Clear legacy Director's Notes** (`"instruction": ""`, `"voiceInstructionMode": "NO_INSTRUCTION"`) to prevent `1.12x` vs `3.84x` whisper RMS flattening; drive delivery via `<Affective Delivery>` + scoped `<instruction id="text normalization for speech">` in `global_instruction.txt`, and opening angle-bracket tags (`<prosody rate="64%"><warm>`) on callback `Part.from_text()` (never closing tags `</prosody>`, never `[warm]`, never on monolithic A2A `gemini-3.1-flash-live`). Note: `A007`/`A008`/`A009` are legacy `gemini-composite-v1`-only checks.
     - **OSI L2 (Data Link / Turn Framing & 5 Levers of Speed)**: **1. Mask** (Callback filler `0.26 s`, Named Two-Part Reply `0.73 s`, Platform filler `0.75–1.0 s` — **forbid** platform filler on `<300 ms` setters or silent-close turns; `T014` & VAD framing); **2. Cut** (0-pass callbacks & `10–19 ms` inline `tools.x()`); **3. Overlap** (`toolExecutionMode: PARALLEL` / `async_tools`); **4. Start Early** (ANI prefetch + `5s` `inactivityTimeout` Remote-Job polling `30.6 s -> 0.14 s`); **5. Shrink** (lean prompts & DTOs).
  2. **Macro-Band 2 — Deterministic Python Harness (`callbacks/` + `session.state` | Tested by `Eval L1: Callback Unit Tests (F1 Bench)`)**:
     - **OSI L5 (Session, Greeting & Identity Gate)**: Guard one-time state seeding with an `_initialized` turn guard in `before_agent_callback`; emit a **0-token greeting (`~150 ms`)**; close terminal turns silently with `[Part.from_text(text="")]` (**never** `parts=[]`, which triggers the deaf-session trap); enforce synchronous `before_model_callback` `Optional[LlmResponse]` Auth Gates (`S003`); obey **`C005`** (*Never branch/regex on caller speech in Python — 11% accuracy*).
     - **OSI L6a (Presentation / Post-Tool Interceptor & Guardrail Hierarchy)**: `<2 ms` `after_tool_callback` deterministic secret/PII/prompt-injection scrubber (`C006`, `S008`, `V005`) + **Guardrail Latency Hierarchy**: prefer `0–1 ms` `contentFilter` and 0-token Guardrail Handoff Intercepts over `llmPolicy` (`~240–340 ms/rule` serial latency).
  3. **Macro-Band 3 — Cognitive Brain & Routing Topology (`agents/*/instruction.txt` & `rootAgent` | Tested by `Eval L0/L3/L4: Lint, Turn & Goldens (F1 Chicane)` + `+1` `ShadowEvals`)**:
     - **OSI L3 (Network / Agent Routing Topology)**: **"Start Simple" Single-Agent Default** (`<=15` tools, `1` pass, `0` transfer bleed) vs **Earned Hub-and-Spoke** (`735 ms` callback transfer vs `1,633 ms` model+rephrase, underscore `childAgents` `S004`, single-parent `S007`, root `end_session` `A005`).
     - **OSI L7 (Application / Cognitive XML Policy & Pattern Graduation)**: Canonical PIF XML (`<role>`, `<persona>`, `<primary_goal>`, `<constraints>`, `<error_protocol>`, `<taskflow>`, `${current_date}` `I001`–`I016`), strict groundedness on `null` or `UNTRUSTED_EXTERNAL_DATA`, and the **4-Gate Graduation Process** (`Self-Steering` & `Slot Filling DAG` marked **Incubating at Gate 1–2**).
  4. **Macro-Band 4 — Tool Transport & Clean Data Facade (`tools/*/python_code.py` | Tested by `Eval L2: Isolated Tool Tests (F1 Dyno)` & `cxas lint`)**:
     - **OSI L4 (Transport / Execution SLA, Concurrency & IDOR)**: **5 Laws of Tool Engineering** — explicit `-> dict` return annotation, **no `None` defaults** (`T011` silent-drop trap), `from ces_requests import ces_requests` / `async_tools` with bounded `<=5 s` client SLAs inside the `30 s` platform harpoon + stateful `503` circuit breakers, and **IDOR state-bound IDs** read from `context.state` (never LLM args).
     - **OSI L6b (Presentation / Clean DTO Facade & Self-Healing)**: **`2,400 -> 32` token Clean DTO compression** (saving `2.4 s` across 5 passes, `T006` — *"It can't leak what it never saw"*), setter docstrings `<=1–2` sentences (`T002`, `T012`), `UNTRUSTED_EXTERNAL_DATA` / `NULL_LEDGER_DATA` envelopes, and self-healing `agent_action` error guidance (`T001`).
- **Minimalist Excalidraw Horizontal Layer Bands**: In `diagrams/*.excalidraw`, represent the stack as 4 clean horizontal pastel macro-bands stacked bottom-to-top (`L1` at base -> `L7` at top, `~30–40` total elements) following `diagrams/architecture.excalidraw`.
